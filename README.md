# 🏗️ Budget Architect

**An Enterprise-Grade Financial Planner & Spending Tracker.**

Budget Architect is a high-precision budgeting tool designed to bridge the gap between "Top-Down" financial planning and "Bottom-Up" spending reality. Built with a focus on data density, visual excellence, and mathematical integrity.

![Dashboard Preview](https://raw.githubusercontent.com/yoodule-dev/budget-architect/main/index.html) *(Note: Placeholder for actual screenshot)*

## 🚀 Key Features

- **Bi-Directional Budgeting:** 
  - **Top-Down:** Set a total monthly income and let the system allocate funds based on industry-standard percentages.
  - **Bottom-Up:** Input specific monthly costs (Rent, Loans, Groceries) and watch the system calculate exactly what your required income must be.
- **Spending vs. Planning:** Unique "Sacred Baseline" logic allows you to track expenses by updating absolute amounts without the system automatically "reassigning" more money to categories.
- **Intelligent Data Handling:** Seamlessly handles everything from ₦10 to ₦1 Septillion with conditional compact notation and hover-to-reveal full precision.
- **Advanced Dashboard:** High-contrast dark mode, mobile-responsive layout, and micro-animations for a premium experience.
- **Purchase Estimator:** Test-drive potential purchases against specific category limits before you spend.
- **Analytics & Tracking:** Built-in hooks for Google Analytics 4 (GA4) and Microsoft Clarity to monitor traffic and user behavior.
- **SEO Optimized:** Enterprise-standard Open Graph and Twitter meta tags for premium social sharing previews.

## 🛠️ Technology Stack

- **Core:** [Vue.js 2.x](https://vuejs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (CDN)
- **Icons:** [Lucide Icons](https://lucide.dev/)
- **Persistence:** LocalStorage API for cross-session data stability.
- **Analytics:** Ready-to-use GA4 & Microsoft Clarity integration.

## 📝 Usage

- **Adjust Sliders:** Define your planning rules (Essentials, Lifestyle, Future).
- **Edit Amounts:** Type absolute numbers in the sidebar to track current balances.
- **Fixed Bills:** Use the Sub-Allocations section for non-negotiable costs like Loans or Family Support.
